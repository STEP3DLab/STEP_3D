# Галерея: видимый возврат из прямой ссылки

Исходная версия: `a314edddf2ceeb910021a7762e37568d6a35d919`.

## Воспроизведение и исправление

В опубликованной галерее открыть `portfolio.html#work-40/2` и закрыть просмотрщик. Фокус возвращался на карточку `work-40`, но её верхняя граница находилась на 811,72 px при высоте окна 757 px. Посетитель с клавиатурой не видел, где оказался.

При ручном закрытии прямой ссылки, у которой нет внутренней отметки открытия из карточки, теперь разрешена нативная прокрутка при возврате фокуса. Кнопка «Закрыть» и Escape показывают карточку целиком: в проверенном окне 1156 × 757 CSS px её границы 271,72–561,97 px. Подмена истории и фильтра осталась прежней. Для обычного открытия из карточки и закрытия при навигации `preventScroll` сохранён, чтобы не вмешиваться в восстановление прокрутки браузером.

Изменены только две одинаковые HTML-копии, регрессионные тесты и этот отчёт. Все 49 карточек, 64 изображения, подписи, атрибуции, стили, направления, сторис и бриф сохранены.
