# ТРИФОТИ: студийная версия / spectrum

Действующая версия: https://step3dlab.github.io/STEP_3D/trifoti/warm/. Историческое имя маршрута сохранено. В каталоге — самостоятельный снимок сайта: 10 кейсов, 2 концепта, 6 направлений услуг и бриф с переходом в Telegram или почту менеджера STEP_3D.

## Обычное обновление

`python3 trifoti-source/warm/premium/apply.py`

Идемпотентный редакционный слой применяется к существующему `trifoti/warm/`, затем синхронизирует `docs/trifoti/warm/`. Код и фотографии базовой версии не импортируются. Последовательность стилей: `style.css` → `warm-theme.css` → `studio-palette.css` → `premium.css`.

Полный `trifoti-source/scripts/build-warm.py` предназначен для контролируемой пересборки: он копирует файлы из изменяющегося базового `/trifoti/`. Не использовать его для обычных исправлений независимого warm. Новый редакционный слой зарегистрирован в нём перед копированием зеркала.

## Визуальная система

Основа палитры: глубокий синий `#18223b`, бирюзовый `#08788c`, синий `#3457d5`, ирисовый `#7250c7`, светлый фон `#f7f8fc`. Градиенты принадлежат интерфейсу; оригинальные фотографии не перекрашиваются. Основная типографика — локальный Manrope, фирменное название сохраняет Unbounded.

Первый экран → избранные реальные работы → шесть направлений → процесс → команда → бриф. Исследования формы, визуализации и журнал доступны ниже в раскрытиях, включая прямые ссылки. Три WebP-визуализации маркированы и весят около 183 КиБ. Остальные изображения загружаются лениво.

## Проверки

`node --test trifoti-source/scripts/test-warm.mjs` — 18 проверок: кейсы и атрибуции, фотографии RED7, независимая навигация, шесть маршрутов, сохранность брифа и идентичность зеркал.

Итоги пяти отдельных ИИ-аудитов и принятые изменения: [PREMIUM-AUDIT-2026-11-06.md](PREMIUM-AUDIT-2026-11-06.md).

Визуальная проверка проведена в облачном браузере на широкой и узких раскладках. Проверки на физических iOS/Android не проводились. Текст хранится у посетителя. По кнопке открывается черновик менеджеру STEP_3D в Telegram или почте. Заказчик отправляет его из выбранного приложения. Длинный бриф можно целиком скопировать или приложить файлом. Главная, портфолио, каталог и подробные кейсы доступны для поисковой индексации.
