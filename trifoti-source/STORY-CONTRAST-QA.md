# Истории: поддержка контрастной системной палитры

Исходная версия: `8060160bc8e5977dac37dab6a207df4e8dc11d1a`.

## Изменение

Одна ограниченная доработка `category-stories.css`, активная только при `forced-colors: active`:

- Подписи квадратных плиток получают непрозрачную системную подложку, чтобы не зависеть от градиента поверх фотографии.
- Заполненные и незаполненные сегменты шкалы отличаются толщиной контура, а не только цветом фона.
- Текст, ссылки, фокус, кнопки и рамки используют системные цвета. Отключённая кнопка не теряет контраст из-за общей прозрачности.
- Системная принудительная перекраска не отключается. Обычная красно-белая палитра, размеры плиток, фотографии, данные, авторство, поведение и локальный бриф не меняются.

Версия ссылки на CSS обновлена. Исходник и оба публикационных зеркала синхронизированы; отдельная warm-версия не затронута.

## Границы проверки

Это проверка структуры CSS и прежних регрессий, не сертификация доступности. Нативная эмуляция forced-colors недоступна: инструменты разработчика браузера запрещены политикой окружения. Запрет не обходился. Локальный HTTP-предпросмотр недоступен из отдельного браузера (`ERR_CONNECTION_REFUSED`). Обычный публичный режим и точная версия выпуска проверяются после публикации; результат отмечается в отчёте о выпуске. Физические устройства и скринридер в этом цикле не проверены.
