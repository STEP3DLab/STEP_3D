# ТРИФОТИ — синяя версия сайта

Опубликованная версия: https://step3dlab.github.io/STEP_3D/trifoti-blue/

Статический сайт без внешних зависимостей. Главная страница, девять проектов, галереи и режим презентации. Три подробные истории: награды СТД России, медведь и кубок Спартакиады РТО.

## Изменение историй

Исходные сведения и медиа: `project-data.js`. Тексты трёх историй: `project-stories.js`. После редактирования выполните из этой папки:

```sh
node scripts/build-stories.mjs
node scripts/sync-pages.mjs
```

Полученные страницы `cases/*.html` и копию `docs/trifoti-blue/` нужно закоммитить. Они работают без JavaScript. Главная использует `app.js` для галереи, фильтров, презентации и подготовки брифа.

Бриф сохраняется на устройстве посетителя или копируется в буфер. Автоматической отправки нет. При переходе из истории проект и направление подставляются в форму.

Оригинальные фотографии, сведения об авторстве и ссылки на публикации сохранены. Технопарк РГСУ и Step3D указаны в соответствующих кейсах; портфолио не означает, что все работы изготовлены под брендом ТРИФОТИ.

В репозитории настроены две публикации GitHub Pages: из корня через workflow и из `docs/` через встроенную сборку. Поэтому `trifoti-blue/` и `docs/trifoti-blue/` должны содержать одинаковую версию сайта. Скрипт `sync-pages.mjs` копирует основную папку в `docs/`, не изменяя другие сайты. Он запускается из основной копии сайта в корне репозитория.
