# Фильтры каталога после готовности JavaScript

## Подтверждённый дефект

При отключённом JavaScript или ошибке загрузки app.js исходный HTML показывал три кнопки фильтра, которые ничего не делали. Все девять проектов оставались доступны, но интерфейс обещал неработающее действие.

## Изменение

- Панель фильтров скрыта в исходном HTML. Она появляется после подключения обработчиков, восстановления фильтра из URL и обновления количества проектов.
- Все девять ссылок на полные кейсы, нативное раскрытие каталога, лёгкий просмотр и каталог для печати остаются доступны без app.js.
- Если отложенная загрузка или переход по истории скрывает карточку с фокусом, фокус переходит на выбранный фильтр без прокрутки. Активный элемент фиксируется до скрытия; видимый фокус не переносится.
- Версии HTML → app и app → portfolio-filters обновлены. Медиа, оформление, атрибуция, бриф, данные и отдельная warm-версия не изменены.

## Проверки перед публикацией

- npm run check: 769/769, включая генераторы страниц и синтаксис модулей.
- Отдельная warm-версия: 16/16.
- Независимое ревью без правок: одобрено после уточнения захвата фокуса, повторены 15/15 профильных и 769/769 основных проверок.
- Новые проверки: статический HTML со всеми девятью ссылками, скрытые неработающие кнопки, раскрытие панели только после готовности, задержанная загрузка, потеря фокуса при скрытии ссылки или кнопки подборки, восстановление по истории и сохранение видимого фокуса.
- 180 исходных файлов идентичны обеим публикационным копиям. Перед публикацией проверены чистая исходная версия 22f71c7, отсутствие другого активного native-редактора и удалённая main.

## Ограничения

Отказы загрузки и отсутствие JavaScript проверены статическим HTML и автоматическими моделями DOM, а не отключением JavaScript в нативном браузере. Независимый локальный Chromium не запустился из-за ограничения sandbox. Публичный каталог проверяется отдельно после развёртывания. Физические телефоны, Safari, Firefox и скринридеры не проверялись. Это точечное улучшение, не заявление о полном соответствии WCAG.
