# ТРИФОТИ — студия скульптуры и предметного дизайна

Публичная статическая версия концепта с медведем, портфолио и локальным конструктором брифа.

Сайт: https://step3dlab.github.io/STEP_3D/trifoti/

## Разработка

HTML, CSS и ES-модули без шага сборки. Редактируйте файлы в `dist/`.

Проверка: `npm run check`. Для локального просмотра запустите `python3 -m http.server 8000 --directory dist` и откройте http://localhost:8000.

При обновлении скопируйте содержимое `dist/` в оба каталога репозитория: `trifoti/` и `docs/trifoti/`. Они должны оставаться идентичными, чтобы сайт работал при обоих действующих способах публикации GitHub Pages. Остальные разделы репозитория менять не нужно.

## Возможности и ограничения

- Пять реальных проектов, 20 фотографий и два исходных видео.
- Медведь в главном блоке: локальные MP4/WebM, постер и GIF-резерв.
- Фильтры портфолио, галереи проектов, переход выбранного проекта в бриф.
- Бриф и заметки сохраняются только в браузере посетителя. Кнопки скачивают текстовые файлы и ничего не отправляют студии.
- Контакты студии будут добавлены после согласования. Backend, аккаунты, база заявок и сторонняя аналитика не подключены.

Все изображения, видео, шрифты и библиотеки находятся в `dist/assets/`. Лицензии шрифтов и Three.js лежат рядом с соответствующими файлами. Предыдущие процедурные модели медведя сохранены как исходные материалы, но сайт их не загружает.

Приватные настройки хостинга, ключи доступа, локальные заметки и техническое окружение в эту публичную копию не включены.

## Управление анимацией

Анимация учитывает системную настройку уменьшения движения и останавливается в скрытой вкладке. Ручная пауза сохраняется при переключении вкладок. На сцене доступны клавиши Пробел/Enter для воспроизведения и паузы, стрелки для поворота; подсказка доступна скринридерам. Кнопка перезапуска возвращает первый кадр и оставляет анимацию на паузе.

`npm run check` также запускает 40 проверок управления видео/GIF, клавиатурного поведения диалогов, локального брифа и превью галерей без сторонних зависимостей. При обновлении связанных клиентских модулей меняйте параметры версий в HTML и импортах, чтобы браузер не смешивал старые и новые файлы.


## Клавиатура в галерее

Tab и Shift+Tab удерживают видимый фокус внутри открытого диалога. Escape и возврат фокуса после закрытия остаются нативными. Обычные стрелки переключают кадры, но сочетания браузера и средств доступности, поля ввода и встроенное управление видео сохраняют своё поведение.


## Надёжность локального брифа

Сохранение использует прежний ключ `trifoti-brief-v1` и те же шесть полей. Ошибки доступа к хранилищу, повреждённый или частично восстановленный черновик показываются явно. Сайт не отправляет бриф и не подтверждает сохранение файла на устройстве: он сообщает только о запросе скачивания. После подготовки доступен текст для ручного копирования, если скачивание не сработало. Обязательные поля не принимают одни пробелы.


## Лёгкие превью галерей

Для ленты миниатюр подготовлены 21 WebP-превью размером 180 × 200 пикселей. Их общий объём составляет 125 972 байта вместо 2 699 104 байт исходных изображений для этой ленты (на 95,3% меньше). Основной просмотр использует прежние оригиналы; исходные фотографии, видео и постеры сохранены. Для кейса с единственным кадром скрытые миниатюры не создаются.

Готовые превью входят в `dist/assets/previews/`. При изменении портфолио их можно пересоздать командой `python scripts/make-media-previews.py`; только для этой необязательной операции нужны Python с Pillow и Node. Обычная работа сайта и `npm run check` не требуют Pillow или сторонних пакетов.
