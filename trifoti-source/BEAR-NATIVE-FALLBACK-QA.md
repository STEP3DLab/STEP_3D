# Встроенное управление медведем при недоступном JavaScript

## Подтверждённая проблема

Исходный HTML показывал кнопки паузы и сброса, а также подсказки клавиатуры и перетаскивания, хотя без JavaScript эти действия не работали. У самого видео не было встроенных кнопок браузера. Ошибка загрузки основного модуля приводила к тому же состоянию. Обработчик ошибки отдельного модуля выключал кнопки, но не давал воспроизвести исправное видео.

## Изменение

- В исходном HTML включено встроенное управление видео, без autoplay. Фирменные кнопки, подсказки и описание клавиатуры становятся доступными только после успешной инициализации.
- До готовности обработчиков сцена не перехватывает клавиши или указатель. Незавершённая инициализация не убирает встроенные кнопки.
- Медленная загрузка модуля сохраняет уже выбранное посетителем воспроизведение или паузу. Фокус с заменяемых встроенных кнопок переносится на сцену без прокрутки.
- Обычная версия сохраняет прежние кнопки, видео, постер и визуальное оформление. Существующие правила уменьшения движения, Save-Data и загрузки GIF только по запросу сохранены.
- Изменены версии URL HTML → app, HTML → CSS и app → bear-video. Публикационные копии синхронизированы.

## Проверки

- Полная команда `npm run check`: 760/760.
- `node --test scripts/test-warm.mjs`: 16/16. Независимая тёплая версия не изменена.
- Независимое ревью и повторный запуск профильных тестов: 49/49.
- Новые тесты покрывают исходный HTML без выполнения JS, успешную и неполную инициализацию, клавиши/указатель при неполной инициализации, задержанную загрузку после нативного play/pause и возврат фокуса.

## Ограничения

Поведение без JS и при сетевой ошибке проверено исходным HTML и моделированием обработчиков, а не нативным отключением JS в браузере. Локальный Chromium не смог запуститься в доступной среде; инструменты разработчика облачного браузера запрещены политикой среды. Физические телефоны, Safari, Firefox, скринридеры и полноэкранное нативное видео не проверялись. Это точечное улучшение, не заявление о полном соответствии WCAG.
