## Автоматические проверки

`npm run check`: 555 тестов проходят (516 прежних и 39 дополнительных). Генерируемые страницы сверены с едиными данными; JavaScript проверен на синтаксис. Все 160 runtime-файлов совпадают в трёх зеркалах.

Новые регрессии исполняют реальные модули в небольшом DOM-harness Node, без browser DevTools и без обхода ограничений:

- Добавление/дедупликация референсов; старое одиночное название; непрозрачный многопараграфный текст; отдельное удаление; подтверждение удаления прежнего текста; атомарная граница 6000 символов.
- Единственная видимая панель и сохранение узла/кадра сравнения при переключении.
- Инъекция отклонённого импорта историй; исключения при частичном построении панели; ошибки загрузки UI подборки. Fallback локален, повторный click не создаёт второй mount, выбор/открытие кейса сохраняются.
- Синхронизация кнопок карточки/кейса, максимум три, выбор внутри открытого модального кейса без смены его URL, сохранение выбора при возврате.
- Удаление последнего выбранного кейса под активным фильтром возвращает фокус видимому фильтру, а не скрытой карточке.
- Масштаб, панорамирование, fit, клавиатура, двухэтапный Escape, сброс при смене кадра/видео. Клавиши браузера не перехватываются; touch-action самого увеличенного изображения допускает обе оси и pinch.
- Все 25 кадров проходят round-trip между modal/static/light; неверные ID не попадают в ссылки. Лёгкий режим не подгружает изображение/видео при восстановлении контекста.
- Статические покадровые ссылки и независимый запрет нативной отправки брифа даже при отсутствии основного модуля.

Прежние тесты обновлены там, где контракт намеренно изменён: CTA теперь раньше медведя, case→brief добавляет результат вместо замены, статические страницы имеют необязательное улучшение контекстных ссылок, изменены версии ресурсов. Проверки оригиналов, шести полей, атрибуций, noindex, истории и локального экспорта не ослаблены.

## Замечания независимого код-ревью

Независимый read-only обзор завершён без открытых замечаний; дополнительный сфокусированный прогон 98 тестов прошёл. Повторный обзор поздних исправлений также не обнаружил замечаний: 67 сфокусированных тестов прошли, все 27 размеров независимо повторно сверены Pillow/ffprobe. Это не заменяет нативную приёмку.

Исправлено до нативной приёмки:

1. Фокус после удаления последней работы, скрытой фильтром.
2. Разрешение горизонтального нативного pan на самом увеличенном IMG, не только на контейнере.
3. Статический import необязательного UI подборки заменён guarded dynamic import.
4. Лимит четвёртой работы объясняется непосредственно у нажатой карточки, а не только в далёкой сводке.
5. Ссылки переключения режима в подписи статического кадра разделены flex-gap с корректной CSS-специфичностью.
6. Для всех 27 исходных медиа/постеров измерены размеры (Pillow/ffprobe), сохранён SHA-256 и заданы width/height статических медиа: lazy-фото без размеров больше не сдвигают якорь кадра при загрузке.
7. Фокус старого zoom-контрола фиксируется до очистки при замене содержимого кейса.

## Нативная приёмка / публикация

Независимая нативная приёмка пройдена при 100% и 250%: карточная/модальная подборка, лимит и локальная подсказка, три панели с сохранением состояния, zoom/fit и двухэтапный Escape, возврат фокуса к активному фильтру после удаления последней скрытой работы, точный red-profile round-trip modal→static→light→modal и Back/Forward, отсутствие автозапуска видео. После исправления размеров hard reload статической страницы удерживает кадр 3/10; ссылки режимов визуально разделены. Узкий hero при 250% показывает CTA до медведя, zoom-кнопки переносятся. Открытых дефектов нет. Синтетические данные брифа удалены, исходное пустое/default-состояние и масштаб 100% восстановлены.

Точный набор отдельных viewport-ширин 360–430 px и landscape не подтверждён; проверку narrow250% нельзя выдавать за physical mobile/landscape. Выпуск разрешён после нативной приёмки; публикация и проверка развёртывания ещё выполняются.

Не проверены и не заявлены: реальные Android/iOS, физический touch/pinch, экранный диктор, native forced-colors, фактическая печать/PDF-пагинация. Предыдущие задачи 24, 39, 48 остаются открытыми; запреты DevTools и Print не обходятся.

## После релиза: контраст выбранного режима исследования — 26 октября 2026

На актуальном `main` (`be9c340b055b200f013b999a3648c08d27a8c5d0`) найден отдельный дефект: общий hover кнопок внутри исследования перекрывал тёмный фон выбранного режима, сохраняя светлый текст. Контраст падал до 1,086:1. Это исправление дефекта, не новая нумерованная серия.

Общий hover теперь исключает `[aria-pressed="true"]`. Выбранная кнопка сохраняет исходные `--ink` / `--paper` при наведении, фокусе и их сочетании; невыбранные кнопки сохраняют прежний hover. Цвета бренда, существующий offset фокуса, логика выбора и остальные панели не меняются. Аналогичные selected-правила фильтров портфолио/публикаций, глав галереи и кнопок подборки просмотрены: такой же конфликт hover не найден, правки им не потребовались.

Добавлена сфокусированная модель каскада в `test-text-contrast.mjs`: два прежних сбоя selected+hover / selected+hover+focus воспроизведены до исправления; после исправления все 24 контрастные проверки и полный `npm run check` (564 теста) проходят. Это статические регрессионные проверки, не замена нативному браузерному тесту. Ключ CSS обновлён на `20261026-selected-contrast`; обе публикационные копии идентичны `dist`. Данные шести кейсов, 25 медиа, атрибуция, биографии, `noindex`, бриф и приватность не затронуты.

Нативная повторная проверка кандидата пройдена, в том числе при эффективном viewport 360 × 505 CSS-пикселей и нативном desktop zoom 150%: выбранный «Атлас кадров» при одновременных `:hover` и `:focus-visible` сохраняет фон `rgb(32,32,30)`, текст `rgb(245,243,238)` и красный контур 2 px; переполнения не обнаружено. Подключена версия CSS `20261026-selected-contrast`. Это не проверка физического телефона или touch. Выпуск разрешён после этой приёмки; результат развёртывания проверяется отдельно.
