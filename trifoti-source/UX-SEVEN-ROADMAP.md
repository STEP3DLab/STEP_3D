# Семь дополнительных значительных улучшений UX/UI

Отдельная серия по запросу 26 октября 2026 года. Не заменяет и не пересчитывает исходные 50 задач. База: `683f42bb5551ba257b97756d7ceb6c56b3ec3a62`; актуальный remote main проверен перед изменениями. Задачи 24, 39 и 48 прежнего плана не закрываются этой серией.

| № | Новый полезный результат | Критерии приёмки |
|---|---|---|
| S1 | Безопасное управление референсами | Кейс добавляется, а не заменяет подборку/старый текст. Дедупликация; лимит 6000 проверяется до изменения. Отдельное удаление распознанного кейса. Неизвестный прежний текст остаётся непрозрачным блоком; его удаление подтверждается отдельно. Прежние шесть полей и ключ черновика сохранены. Это исправление всего жизненного цикла референса, не повтор задачи 38. |
| S2 | Один рабочий режим исследования за раз | Подборка/сравнение, визуальные истории и атлас разделены на три переключаемые панели. Состояния просмотров не пересоздаются при смене панели; остаются маршруты, история, фокус и ссылки. |
| S3 | Действие до большой сцены на мобильном | CTA «Посмотреть проекты» расположен перед медведем и в DOM, и визуально. Сохранены текст, четыре направления и управление анимацией. Высота сцены ограничена на коротких экранах, оригинал вписан без обрезки. Нативная проверка узких экранов и 250% обязательна. |
| S4 | Изучение фотографии внутри кейса | Тот же оригинал: масштаб 100–400% относительно вписанного кадра, кнопки перемещения, клавиатура, вписывание. Первый Escape снимает увеличение, следующий закрывает кейс. Новый кадр сбрасывает масштаб. Ссылка на оригинал остаётся; видео не меняются. Нативные pinch/touch отдельно не заявляются без устройства. |
| S5 | Подборка там, где выбирают работы | Кнопка рядом с карточкой и в открытом кейсе; одно состояние с прежним исследованием, максимум три работы. Компактная сводка видна только при непустом выборе, позволяет убрать одну работу, перейти к сравнению/встрече. Нет вложенных интерактивных ссылок, самопроизвольного скролла или скрытого фокуса. |
| S6 | Тот же кадр во всех способах просмотра | Модальная галерея, статическая страница и лёгкий просмотр передают только проверенные публичные ID кейса/кадра. Работают обратные переходы, неизвестные ID безопасны, видео не запускается. Статические ссылки конкретных кадров доступны без JS. |
| S7 | Отказ необязательного инструмента не останавливает сайт | Истории, исследование, UI подборки и подсказки брифа загружаются через независимые guarded imports. Ошибка импорта/инициализации локальна и предлагает статический каталог; основные галерея/бриф/меню продолжают работу. Нет автоповторов/перезагрузки, двойного mount или отправки формы при сбое app. |

## Статус кандидата

Все семь реализованы и покрыты автоматическими регрессиями. Независимые код-ревью и нативная приёмка desktop/250% пройдены; открытых дефектов нет. Выпуск разрешён, публикация и проверка развёртывания выполняются отдельно. Физические мобильные устройства и отдельная серия измеренных ширин/landscape не проверены и не заявлены.
