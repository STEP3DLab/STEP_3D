# Резерв страницы показа при сбое загрузки

## Подтверждённый дефект

Если meeting.js или один из его импортов не загружался, посетитель с уже выбранными работами видел указание выбрать их заново. Прямые ссылки на кейсы находились только внутри noscript и не были доступны при сетевой ошибке с включённым JavaScript.

## Изменение

- Исходный HTML объясняет, что показ открывается, и предлагает обновление страницы или полные страницы всех девяти реальных работ. Ссылки доступны без выполнения скриптов, а не только при отключённом JavaScript.
- Указание выбрать работы появляется только после успешной инициализации и проверки отсутствия корректной подборки. Резерв скрывается после успешного первого рендера.
- Ссылка перехода к кадру доступна только при наличии кадра. Если отложенная загрузка или смена маршрута скрывает сфокусированный элемент, фокус переходит в видимый показ или на выход без прокрутки. Стабильный внешний фокус не меняется.
- Медиа, подписи, атрибуция, работа брифа и сетевое поведение не изменены. Новые хранилища и запросы не добавлены. URL модуля обновлён, обе публикационные копии синхронизированы.

## Проверки

- Основная проверка npm run check: 765/765.
- Независимая warm-версия: 16/16, без изменений.
- Независимое ревью без правок: профильные 64/64 и основные 765/765, без обязательных замечаний.
- Новые проверки охватывают исходный HTML без выполнения JS, все девять ссылок вне noscript, обычную и неполную инициализацию, ошибку первого рендера, задержанную загрузку с фокусом на резервной ссылке, пустой/корректный маршрут и скрываемую ссылку к кадру. Прежние проверки повторных событий, видео и клавиатуры сохранены.
- 180 файлов dist совпадают с trifoti/ и docs/trifoti/. Другой активный редактор не обнаружен; удалённая main до публикации совпадала с 9333cc7.

## Ограничения

Сетевые отказы и отключённый JavaScript проверены по статическому HTML и модели DOM, а не отключением JS в нативном браузере. Облачный браузер не подключается к локальному проверочному серверу (ERR_CONNECTION_REFUSED). Обычный публичный показ проверяется отдельно после развёртывания. Физические телефоны, Safari, Firefox и скринридеры не проверялись. Это точечное исправление, не заявление о полном соответствии WCAG.
