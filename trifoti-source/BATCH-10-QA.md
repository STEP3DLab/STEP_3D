Кандидат от 26 октября 2026. База: 02c123815db840c6a34009fd39c2fd2c13db46ff, перед работой сверена с публичной main. Независимая нативная приёмка пройдена. Публикация и проверка развёртывания ожидаются.

## Результат

- **46. Шесть статических кейсов.** Страницы `cases/<key>.html` генерируются из неизменённого project-data.js. Все 23 фотографии, 2 видео, подписи, блоки описания, атрибуция и источники сохранены. Без JavaScript доступны полные страницы и оригиналы; основные карточки ведут на них нативно. При работающем JavaScript по-прежнему открывается диалог. Старые hash-адреса работают.
- **47. Метаданные конкретных кейсов.** У каждой страницы уникальные title, description, canonical, Open Graph и Twitter Card; превью использует реальный первый кадр/постер кейса, абсолютный публичный URL и точную подпись. Существующие метаданные главной с утверждённым логотипом сохранены. noindex,nofollow не снят. Это проверка HTML и существования активов, не обещание одинакового отображения всеми мессенджерами.
- **48. Каталог.** catalog.html содержит шесть кейсов из тех же данных, обложки, подписи, краткие тексты, источники и прямые ссылки. Видео заменены постером/ссылкой. CSS предусматривает отдельные страницы кейсов, A4 и вывод URL. **Реальная пагинация PDF не проверена; задача 48 полностью не принята.** Печать вызывается штатно, факт сохранения PDF не заявляется.
- **49. Измеримо лёгкий вариант.** light.html сначала загружает только текст и управление. Явный переключатель включает шесть небольших постеров; оригинал каждого текущего кадра загружается отдельной кнопкой. Переключение кадра в текстовом режиме не загружает фото. Для видео сначала открывается управление с preload=none, воспроизведение остаётся отдельным нативным действием. Все подписи, исходные ссылки, атрибуции, переходы в обычную галерею и к существующему брифу сохранены. Нет дополнительного хранилища или автодвижения.
- **50. Встреча.** Ссылка в существующей подборке открывает `meeting.html#show/<ids>/<frame>`. Показ включает только выбранные работы, без меню сайта и формы. Переключение ручное: кнопки, стрелки, Home/End, выбор работы; видимый выход и Escape. Смена кадра заменяет текущий URL, а не заполняет историю; Back возвращает предыдущую страницу. Выход восстанавливает подборку и фокус к ссылке запуска после загрузки. Временный маркер from=meeting удаляется из адреса. Активное видео при уходе/смене кадра приостанавливается; оно не запускается само.

Favicon одинаково исключён из обеих сторон: браузер может кэшировать его отдельно. Без этого исключения исходная загрузка — 39 запросов / 1 321 752 байта. Текстовый вариант передаёт на 96,74% меньше байтов; вариант с постерами — на 92,90% меньше. Это **не сравнение визуально одинаковых экранов и не измерение времени загрузки**: экономия достигается намеренным отложенным показом необязательных медиа и использованием системного шрифта. Реальная скорость сети и мобильного устройства не измерялась.

Явная загрузка оригинала серии наград добавила один запрос / 125 058 байт. Следующий кадр в текстовом режиме не добавил запросов. Включение постеров добавило ровно шесть изображений, ни одного видео.

Финальные загрузки текста и постеров повторены независимым нативным проверяющим после уточнения подписей. Полные пути, коды ответов и байты записаны в [scripts/lightweight-measurements.json](scripts/lightweight-measurements.json). Измеритель — scripts/preview-measure.py; он используется только локально, не подключён к сайту и не создаёт аналитику.
