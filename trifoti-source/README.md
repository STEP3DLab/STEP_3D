# ТРИФОТИ — творческое объединение

Публичная статическая версия концепта с медведем, портфолио и локальным конструктором брифа.

Сайт: https://step3dlab.github.io/STEP_3D/trifoti/

## Разработка

HTML, CSS и ES-модули без шага сборки. Редактируйте файлы в `dist/`.

Проверка: `npm run check`. Для локального просмотра запустите `python3 -m http.server 8000 --directory dist` и откройте http://localhost:8000.

При обновлении скопируйте содержимое `dist/` в оба каталога репозитория: `trifoti/` и `docs/trifoti/`. Они должны оставаться идентичными, чтобы сайт работал при обоих действующих способах публикации GitHub Pages. Остальные разделы репозитория менять не нужно.

## Возможности и ограничения

- Шесть реальных проектов, 23 фотографии и два исходных видео.
- Медведь в главном блоке: локальные MP4/WebM, постер и GIF-резерв.
- Фильтры портфолио, галереи проектов, переход выбранного проекта в бриф.
- Бриф и заметки сохраняются только в браузере посетителя. Кнопки скачивают текстовые файлы и ничего не отправляют объединению.
- Контакты объединения будут добавлены после согласования. Backend, аккаунты, база заявок и сторонняя аналитика не подключены.

Все изображения, видео, шрифты и библиотеки находятся в `dist/assets/`. Лицензии шрифтов и Three.js лежат рядом с соответствующими файлами. Предыдущие процедурные модели медведя сохранены как исходные материалы, но сайт их не загружает.

Приватные настройки хостинга, ключи доступа, локальные заметки и техническое окружение в эту публичную копию не включены.

Кейс из портфолио STEP_3D, реализованный командой Технопарка РГСУ: цифровое проектирование, 3D-печать и вручение наград при участии Владимира Машкова. Три подлинные фотографии показывают готовые награды, церемонию и процесс работы. Источники и атрибуция: `CASE-SOURCES.md`.


## Управление анимацией

Анимация учитывает системную настройку уменьшения движения и останавливается в скрытой вкладке. Ручная пауза сохраняется при переключении вкладок. На сцене доступны клавиши Пробел/Enter для воспроизведения и паузы, стрелки для поворота; подсказка доступна скринридерам. Кнопка перезапуска возвращает первый кадр и оставляет анимацию на паузе.

`npm run check` также запускает 192 проверки управления видео/GIF, клавиатурного поведения диалогов, локального брифа, превью галерей, навигации по проектам, панели заметок и восстановления медиа без сторонних зависимостей. При обновлении связанных клиентских модулей меняйте параметры версий в HTML и импортах, чтобы браузер не смешивал старые и новые файлы.


## Клавиатура в галерее

Tab и Shift+Tab удерживают видимый фокус внутри открытого диалога. Escape и возврат фокуса после закрытия остаются нативными. Обычные стрелки переключают кадры, но сочетания браузера и средств доступности, поля ввода и встроенное управление видео сохраняют своё поведение.


## Надёжность локального брифа

Сохранение использует прежний ключ `trifoti-brief-v1` и те же шесть полей. Ошибки доступа к хранилищу, повреждённый или частично восстановленный черновик показываются явно. Сайт не отправляет бриф и не подтверждает сохранение файла на устройстве: он сообщает только о запросе скачивания. После подготовки доступен текст для ручного копирования, если скачивание не сработало. Обязательные поля не принимают одни пробелы.


## Лёгкие превью галерей

Для ленты миниатюр подготовлены 24 WebP-превью размером 180 × 200 пикселей. Их общий объём составляет 150 872 байта вместо 2 995 850 байт исходных изображений для этой ленты (на 95,0% меньше). Основной просмотр использует прежние оригиналы; исходные фотографии, видео и постеры сохранены. Для кейса с единственным кадром скрытые миниатюры не создаются.

Готовые превью входят в `dist/assets/previews/`. При изменении портфолио их можно пересоздать командой `python scripts/make-media-previews.py`; только для этой необязательной операции нужны Python с Pillow и Node. Обычная работа сайта и `npm run check` не требуют Pillow или сторонних пакетов.


## Прямые ссылки на проекты

Каждый из шести проектов доступен по адресу `#project/<ключ проекта>`, например `https://step3dlab.github.io/STEP_3D/trifoti/#project/stdAwards`. Открытие карточки создаёт один шаг истории, поэтому работают кнопки браузера Назад/Вперёд и обновление страницы. Закрытие прямой ссылки возвращает к портфолио, не уводя посетителя с сайта. Существующие якоря и фильтры сохраняются.

Кнопка «Скопировать ссылку на проект» работает только по явному нажатию. Ссылка использует текущий домен и путь без посторонних параметров запроса. Если буфер обмена недоступен, показывается поле для ручного копирования. Новые хранилища или отправка данных не добавляются.


## Устойчивость панели заметок

Панель использует прежний ключ `trifoti-review-v1` и только поля `sections` и `notes`. Повреждённые старые данные не мешают загрузке портфолио, брифа и медведя: корректные заметки и решения восстанавливаются по возможности, а проблемы чтения или сохранения показываются явно. Ошибка загрузки необязательной панели не останавливает основные функции сайта. Заметки не отправляются объединению; экспорт сообщает о запросе скачивания, а не о подтверждённом сохранении файла.


## Повторная загрузка медиа

Если фотография или видео в галерее не загрузились, появляется кнопка «Повторить загрузку». Каждое явное нажатие запускает одну попытку для того же оригинального файла и кадра; автоматических повторов нет. Повторный сбой остаётся видимым и допускает новую попытку. Запоздавшие события прежних кадров или закрытой галереи игнорируются, а скрытие кнопки после успеха не теряет клавиатурный фокус.


## Понятные подписи элементов

У четырёх ссылок обсуждения услуги доступны контекстные названия с сохранением видимого текста. Два ранее обязательных поля брифа также явно помечены словом «обязательно»; бюджет и срок остаются необязательными. Поля, переходы и правила хранения не меняются.



## Безопасная готовность брифа

Кнопка скачивания сначала недоступна и включается только после подключения локальной обработки формы. При отсутствии JavaScript или сбое загрузки форма не переходит к обычной GET-отправке данных. Начальное сообщение объясняет недоступность сохранения; поля, ключи хранилища и сетевое поведение не расширяются. При высоте окна до 500 пикселей кнопка заметок находится в обычном потоке после подвала и не перекрывает поля брифа.



## Объединение, направления и разделы

ТРИФОТИ представлено как творческое объединение с четырьмя направлениями: «Дизайн и архитектура», «Скульптура», «Бытовой дизайн», «Сувениры, призы, награды». Направления согласованы между услугами, фильтрами портфолио и локальным брифом. Категории без добавленных работ показывают честное пустое состояние с переходом к обсуждению. Пять существующих кейсов и все исходные медиа сохранены.

В команде указаны Фёдор, Оксана, Христина и Владимир; для Оксаны обозначено направление «Дизайн». Раздел «Новости и блог» содержит три истории существующих проектов, а дата церемонии наград обозначает само событие. Четырёхколоночный подвал с адаптивной раскладкой ведёт только к существующим разделам и кейсам.

Старые названия направлений в черновиках сопоставляются только там, где соответствие однозначно. Сохранённый вариант «3D-модель и производство» остаётся доступен без переназначения. Ключи и поля локального хранения не меняются; панель заметок показывает новое название объединения, сохраняя прежний внутренний ключ раздела.



## Публикации и интервью

Раздел журнала дополнен шестью избранными материалами и раскрывающимся каталогом из 21 проверенного источника о скульпторе Фёдоре Паршине. Короткие авторские аннотации ведут на оригинальные страницы изданий; статьи, изображения и записи не копируются. Даты сохраняют точность источника, отсутствующие даты не угадываются. Исторический статус проектов и авторство указаны отдельно.

Редакционные данные находятся в `dist/publications-data.js`. После их изменения выполните `npm run build:publications`, затем `npm run check`. Генератор `scripts/render-publications.mjs` обновляет только отмеченный блок каталога в HTML. Все ссылки доступны без JavaScript; необязательный модуль фильтров лишь скрывает неподходящие записи и сообщает количество. Внешние плееры, трекеры и новые хранилища не добавлены. Список источников: `PRESS-SOURCES.md`.



## Контраст вторичного текста

Вторичный текст и подсказки полей используют цвет `#62625d`, а небольшие красные подписи, ссылки при наведении и заголовки услуг на узких экранах используют `#bf1230`. Для проверенных сочетаний обычного текста контраст составляет не менее 4,5:1. Яркий фирменный красный в крупных заголовках, фоны кнопок, медиа и декоративные элементы сохранены.

Проверки в `scripts/test-text-contrast.mjs` рассчитывают относительную яркость sRGB и проверяют реальные CSS-правила для светлых фонов, карточек, подвала, подсказок и обратной связи. Это ограниченное улучшение читаемости, а не заявление о полном соответствии WCAG.



## Мобильное меню и клавиатура

В исходном HTML кнопка меню предшествует ссылкам навигации, поэтому Tab и Shift+Tab проходят по ним в естественном порядке без перехвата клавиш. Внешняя раскладка шапки сохранена через CSS. Escape закрывает меню и возвращает фокус на кнопку; выход фокуса за пределы шапки закрывает меню без переноса фокуса. При смене ширины через границу 800 пикселей фокус переносится только с элемента, который становится скрытым, без прокрутки. Контент, анимация, данные и сетевое поведение не меняются.


## Упаковка шрифтов

Те же три локальных шрифта загружаются как WOFF2 без сокращения набора символов или изменения начертаний. Их общий размер составляет 386 100 байт вместо 1 115 060 байт исходных TTF (на 65,4% меньше). Это сравнение размеров файлов, а не измерение времени загрузки. Исходные TTF и лицензии OFL сохранены рядом.

Источники, лицензии и подробности проверки: `FONT-SOURCES.md`. Обычные проверки не требуют сторонних пакетов. Необязательная команда `npm run check:font-equivalence` использует Python fontTools и встроенный Brotli-декодер Node.js, чтобы сверить все глифы, метрики и таблицы с оригиналами.


## Доступное закрытие галереи

Кнопка закрытия проекта находится в отдельной непрокручиваемой строке диалога, поэтому остаётся видимой при просмотре длинного кейса на узком экране. Прокручивается только содержимое; кнопка не перекрывает фотографии и текст. При открытии другого кейса внутренняя прокрутка сбрасывается. Существующие Escape, Tab, история, ссылки и возврат фокуса сохраняются.


## Кубок Спартакиады РТО

Шестой кейс, `rto-traveling-cup`, представляет переходящий кубок Спартакиады РТО из портфолио STEP_3D. Разработка и производство атрибутированы Step3D. Три подлинные фотографии дополнены компактными превью; ссылки ведут на исходный проект и официальные итоги события 2026 года. Пять прежних кейсов и все их медиа сохранены. В категории наград теперь два проекта; ссылки, галерея и перенос выбранного проекта в локальный бриф используют существующие механизмы. Источники: `CASE-SOURCES.md`.


## Подписи на карточках проектов

Подписи количества медиа переносятся на новые строки, не обрезаясь и не перекрывая стрелку открытия. Ограничение ширины учитывает существующие отступы, размер стрелки и зазор 8 пикселей. Тексты, шрифты, цвета, изображения и JavaScript не меняются.


## Шапка при сильном увеличении

На ширине до 340 CSS-пикселей логотип и полноразмерная кнопка меню располагаются в первом ряду, а ссылка обсуждения проекта переносится во второй. Высота шапки растёт по содержимому; открытая навигация начинается под всей шапкой и сохраняет собственную прокрутку. Элементы не скрываются, горизонтальное переполнение не маскируется; обычная мобильная и настольная раскладка сохраняются.
