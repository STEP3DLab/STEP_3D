# Фокус при возврате между кадрами показа

Исходная версия: `3d98a699ab399659ca3b22fe615943bcccf40f38`.

## Подтверждённая ошибка

В опубликованном Chrome открыт `meeting.html#show/gesture,pink/1`, затем в той же вкладке `#show/gesture,pink/0`. После нажатия «Показать управление видео» фокус переведён на нативное видео. Возврат браузером Назад менял кадр на фотографию, но `document.activeElement` становился `BODY`.

Причина: синхронизация маршрута очищала медиа раньше, чем отрисовка проверяла фокус. Удалённый видеоэлемент уже не мог быть распознан как активный.

## Исправление

- Для действительного маршрута медиа заменяет сама отрисовка, после проверки фокуса. Фокус удалённого видео возвращается на стабильную область текущего кадра.
- Если маршрут скрывает весь показ, фокус из него переводится на видимую ссылку выхода. Фокус за пределами показа не затрагивается.
- Повторные события одного маршрута не пересоздают видео. Обычное листание, выбор работы, подписи, авторство, точные ссылки, пауза старого видео и отсутствие автовоспроизведения сохранены.
- Параметр версии обновлён только для `meeting.js`. Основной дизайн, портфолио, медведь, бриф, локальное хранение и warm-версия не изменяются.

## Проверки до публикации

- Восемь новых регрессионных тестов: `hashchange`, `popstate`, фокус видео, сохранение фокуса навигации, некорректный маршрут и повторные события. Имитация DOM теперь сбрасывает фокус при удалении активного дочернего элемента.
- До исправления четыре проверки воспроизводили ошибку; после исправления 44/44 теста ресурсов прошли.
- `npm run check`: 684/684. `test-warm.mjs`: 16/16.
- Независимое read-only ревью: блокеров нет, полный набор проверок повторно прошёл.
- Все 180 файлов `dist/` идентичны двум публичным копиям. `git diff --check` без замечаний.

## Границы проверки

Автотесты используют имитацию DOM. Локальный HTTP-предпросмотр не доступен из выделенного браузера; опубликованная версия проверяется отдельно после публикации с подтверждением точного коммита и файлов. Физические телефоны, скринридер и браузеры кроме Chrome в этом цикле не проверяются.
