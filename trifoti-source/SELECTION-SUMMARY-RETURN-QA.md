# Возврат после удаления последней работы из подборки

Дата: 6 ноября 2026 года. База: `5f0c280`.

## Воспроизведение

На публичной красно-белой версии открыть «Все проекты», добавить медведя в подборку, затем нажать «Убрать» в блоке «Ваша подборка» над каталогом. Блок скрывается, а фокус возвращается на кнопку карточки с `preventScroll: true`. В Chromium при ширине 1182 CSS px кнопка оставалась ниже экрана: top 1361, bottom 1405, высота окна 756. Повторное чтение после завершения перехода подтвердило положение.

## Исправление

При удалении последней работы разрешена обычная прокрутка браузера при возвращении фокуса. Сохранился выбор доступной цели: кнопка карточки, активный фильтр либо заголовок свёрнутого каталога. При оставшихся работах фокус по-прежнему остаётся внутри подборки без принудительной прокрутки. Нет новых обработчиков прокрутки, таймеров, хранилищ или запросов. Обновлены версии модуля и точки входа.

## Проверка

- Четыре регрессионные проверки воспроизвели ошибку до правки и прошли после неё: карточка, скрытая фильтром карточка, свёрнутый каталог и удалённая карточка.
- Пятая проверка сохраняет локальный фокус при оставшихся работах и проверяет версии импортов.
- `npm run check`: 827/827.
- `node --test scripts/test-warm.mjs`: 18/18.
- Предпросмотр Chromium: при 1182 CSS px возврат к карточке стал видимым (top 403, bottom 447). При 394 CSS px: карточка 142–186, активный фильтр 169–213, заголовок свёрнутого каталога 91–153, оставшаяся строка подборки 142–186; шапка до 74, высота окна 252. Горизонтального переполнения нет.
- Узкая раскладка проверена масштабом Chromium 300%, не на физическом телефоне. Safari, Firefox и скринридеры не проверялись.
