# Галерея: короткий экран без пустой полосы

Исходная версия: `8ab4581b45dfafe7e03841b30a0fb1fda52f8307`.

## Воспроизведённая проблема

На живой странице `warm/portfolio.html#work-09` в Chromium при 578 × 378 CSS px (масштаб страницы 200%) фото ограничено высотой 49dvh, но контейнер `.viewport` сохранял 68dvh. Высота фото была 185,46 px, контейнера 257,38 px. Лишние 71,92 px пустого места отодвигали кнопки листания: нижняя граница кнопок 387,05 px выходила за экран высотой 378 px.

## Ограниченное исправление

Существующее правило `max-height:580px` теперь задаёт `height:49dvh` самому контейнеру, а не `max-height` только изображению. Фото по-прежнему показывается целиком через `object-fit:contain`. Правила обычного экрана 68dvh и узкого высокого экрана 59dvh сохранены. Прокрутка длинного диалога остаётся доступной.

Обе HTML-копии совпадают. Скрипты, 49 карточек, 64 изображения, подписи, атрибуция, ссылки и локальный бриф не изменены.
