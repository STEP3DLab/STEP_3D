# Мобильное меню: нативные переходы по ссылкам

Исходная версия: `7dcb7670867e4b89d965ffd70bb798f9ac81c451`.

## Исправление

На опубликованном сайте в Chrome при ширине 472 CSS px (увеличение 250%) воспроизведено: Ctrl+click по пункту основного меню открывает новую вкладку, но одновременно закрывает меню в исходной вкладке. Фокус теряется и оказывается на BODY.

Теперь меню закрывается только при обычном переходе левой кнопкой или активации ссылки клавиатурой. Модификаторы Ctrl, Cmd, Shift и Alt, неосновные кнопки и уже обработанное событие не меняют состояние текущего меню. Нативное поведение ссылки не отменяется. Escape, нажатие вне шапки, выход фокуса и смена ширины работают по-прежнему.

Параметр версии независимого модуля навигации обновлён. Дизайн, контент, реальные материалы, направления, атрибуция, истории и локальный бриф не изменены. Warm-версия не редактировалась; проверка её навигационного модуля привязана к прежнему хешу вместо изменяемого основного сайта.
